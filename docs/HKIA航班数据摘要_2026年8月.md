### 航班状态说明

| 状态关键词 | 含义 |
|:---|:---|
| `At gate HH:MM` | 已降落并停靠登机口（附实际时间） |
| `Dep HH:MM` | 已起飞（附实际时间） |
| `Landed HH:MM` | 已降落 |
| `Est at HH:MM` | 预计到达/起飞时间 |
| `Cancelled` | 已取消 |
| `Delayed` | 延误 |
| `Diverted` | 备降 |
| `Scheduled` | 计划中（未变动） |

## 五、使用说明

### JSON 文件结构

```json
{
  "metadata": { ... },       // 元数据及字段说明
  "arrivals": [ ... ],       // 到达航班数组
  "departures": [ ... ]      // 出发航班数组
}
```

### 读取示例

**Python：**
```python
import json

with open('hkg_all_flights_0816_0831.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 查询某日所有到达航班
aug_20_arrivals = [r for r in data['arrivals'] if r['date'] == '2026-08-20']

# 查询某航班号
cx782 = [r for r in data['arrivals'] if r['flight_number'] == 'CX 782']
```

**Excel / Google Sheets：**
- 直接导入 `hkg_arrivals_clean.csv` 或 `hkg_departures_clean.csv`
